# Walk the Walk – Adventure Replay

**▶️ Open the app: https://jonasprobst.github.io/walkthewalk/**

Replay GPS tracker trips (Columbus CSV or GPX) on a map, with a buddy character, rainbow trail, speedometer and stats.

- Optional extras: rooftop detector, secret powers, sounds, coins
- Optional 3D mode for trips in Switzerland (swisstopo terrain, aerial imagery and swissBUILDINGS3D)
- Trips are loaded from files on the device and saved only in that browser; nothing is uploaded

The version number is shown at the bottom of the start screen, next to **Get newest version**, which reloads the app past the browser cache and keeps saved trips.

Map data © OpenStreetMap contributors · 3D data © swisstopo
